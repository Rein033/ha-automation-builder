What can HA Automation Builder do?

    
Build Home Assistant automations with simple forms: pick triggers, conditions and actions, start from ready-made examples, and copy clean automation YAML. Paste existing YAML to edit it.

    
  • Triggers: state, time, sun, numeric value, zone, time pattern, Home Assistant start, event and webhook
  • Conditions: state, time and weekdays, sun, numeric value, zone and template
  • Actions: lights, switches, scenes, scripts, notifications, delays, wait, any action call with data
  • Ready-made examples: lights at sunset, motion light, washing machine done, leave home, and more
  • New syntax (2024.10+) or classic syntax for older versions
  • Paste existing automation YAML to load and edit it; unknown parts are kept as raw YAML

  

  
Frequently asked questions
How do I add the YAML to Home Assistant?
Go to Settings → Automations & scenes → Create automation, open the ⋮ menu, choose Edit in YAML, paste the YAML and save. You can switch back to the visual editor any time.
What is the difference between the new and classic syntax?
Since Home Assistant 2024.10 automations use triggers:, conditions: and actions: with trigger: and action: keys. Older versions use trigger:, platform: and service:. The builder can output both.
Can I edit an automation I already have?
Yes. Click Paste YAML and paste your automation. Known triggers, conditions and actions become forms; anything else is kept as raw YAML so nothing gets lost.
What does the mode setting do?
It decides what happens when the automation is triggered while it is still running: single ignores the new run, restart starts over (great for motion lights), queued waits its turn and parallel runs both.
